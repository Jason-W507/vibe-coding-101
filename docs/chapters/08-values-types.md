# 变量、值、类型与表达式

程序需要处理信息，也需要给信息起名字。理解变量、值和类型，可以从一句简单代码开始：

```python
pages_read = 48
print(pages_read)
```

输出是 `48`。`pages_read` 是名字，`48` 是这里使用的值。赋值语句让后面的代码可以通过这个名字使用相应对象。

## 名字与对象不要混为一谈

把变量理解为“给数据贴标签”，在 Python 中是一个有用的起点。同一个名字可以重新绑定到另一个对象，多个名字也可能指向同一个对象。

```python
titles = ["计算机如何工作"]
alias = titles
alias.append("程序如何表达想法")
print(titles)
```

输出是 `['计算机如何工作', '程序如何表达想法']`。第二行没有复制一份独立列表，而是让 `alias` 和 `titles` 指向同一列表。通过其中一个名字修改它，另一个名字也会观察到结果。[Python 关于名称与对象的说明](https://docs.python.org/3/tutorial/classes.html#a-word-about-names-and-objects)解释了这种关系。

如果之后给 `alias` 重新赋值为另一个列表，改变的是这个名字指向哪里，不会自动把 `titles` 也重新绑定。看代码时，区分“改对象”和“改名字的绑定”，能避免很多困惑。不同语言对变量的具体规则还会有所不同，类比需要服从语言本身。

## 类型决定怎样解释和操作

`12` 和 `"12"` 看起来相近，前者在这个例子里是整数，后者是字符串，也就是文本。它们适合的操作不同。

```python
print(12 + 3)
print("12" + "3")
print(int("12") + 3)
```

三行分别输出 `15`、`123`、`15`。字符串相加在这里执行连接；`int` 尝试按相应规则把文本转换成整数。遇到不能转换的文本时，转换也可能失败。

常见类型还包括表示真假的布尔值，以及表示“没有这个值”等情形的特殊值。Python 使用 `True`、`False` 和 `None` 这些名称。`0`、空文本 `""` 与 `None` 不应仅凭“好像都没有东西”就随意互换，它们在具体规则中可能具有不同含义。

**动态类型**也不意味着对象没有类型。它描述的是语言如何安排类型信息与名称等关系。类型注解则可以帮助人和工具理解意图；Python 不会仅凭一条注解，就自动在运行时阻止所有不合类型的输入。[Python 类型注解文档](https://docs.python.org/3/library/typing.html)明确说明了这一边界。

## 表达式怎样得到结果

能够按规则求出一个值的表达形式，可以称为表达式。`12 * 8` 是表达式，比较 `pages_read > 0` 也是表达式。运算符决定执行哪种操作，括号则可以明确组织顺序。

名字取什么不会自动决定业务含义。把变量命名为 `valid_count`，不等于它已经通过了检查；把字符串命名为 `number`，也不会把它自动变成数字。含义需要由实际代码和输入规则落实。

## 数字表示也有限制

计算机里的小数常使用浮点表示，它能够覆盖很大的数值范围，却不能精确表示所有十进制小数。在通常的 Python 浮点运算中：

```python
print(0.1 + 0.2)
```

会看到 `0.30000000000000004`。这与二进制浮点的表示方式有关，不是程序随意算错了一次。显示时的舍入、计算时的表示和业务上允许的精度是三个相关但不同的问题。涉及精确十进制规则时，需要选择合适的数据表示和处理方法。[Python 的浮点运算说明](https://docs.python.org/3/tutorial/floatingpoint.html)进一步解释了这一现象。

当 AI 修改一段代码时，可以先看数据从哪里来、是什么类型、经过了哪些转换，以及多个名字是否共享同一对象。这些线索经常比变量名本身更能解释程序行为。
