# 变量、值、类型与表达式

程序需要处理信息，也需要给信息起名字。理解变量、值和类型，可以从一句简单代码开始：

```python
pages_read = 48
print(pages_read)
```

输出是 `48`。`pages_read` 是变量名，`48` 是这里使用的值。赋值语句让后面的代码可以通过这个名字访问内存中对应的**对象**（即运行时一份具有类型和值的具体数据）。

## 名字与对象不要混为一谈

把变量理解为“给数据贴标签”，在 Python 中是一个有用的起点。同一个名字可以重新绑定到另一个对象，多个名字也可能指向同一个对象。

```python
titles = ["计算机如何工作"]
alias = titles
alias.append("程序如何表达想法")
print(titles)
```

输出是 `['计算机如何工作', '程序如何表达想法']`。第二行没有复制一份独立列表，而是让 `alias` 和 `titles` 指向同一列表。通过其中一个名字修改它，另一个名字也会观察到结果。[Python 关于名称与对象的说明](https://docs.python.org/3/tutorial/classes.html#a-word-about-names-and-objects)解释了这种关系。

如果之后执行 `alias = ["另一份列表"]`，改变的只是 `alias` 这个名字重新指向了新列表，不会改变 `titles` 原先指向的列表；而如果确实想要一份互不影响的浅层副本，则需要显式复制（如 `titles.copy()`）。看代码时，区分“**原地修改对象内容**（如 `.append()`）”和“**把名字重新绑定到新对象**（`=`）”，能避免很多困惑。不同语言对变量的具体规则还会有所不同，类比需要服从语言本身。

## 类型决定怎样解释和操作

`12` 和 `"12"` 看起来相近，前者在这个例子里是整数，后者是字符串，也就是文本。它们适合的操作不同。

```python
print(12 + 3)
print("12" + "3")
print(int("12") + 3)
```

三行分别输出 `15`、`123`、`15`。字符串相加在这里执行拼接；`int` 按十进制规则把文本转换成整数。遇到不能转换的文本（如 `int("三本")` 或 `int("12.5")`）时，程序会抛出 `ValueError` 异常（见[第 12 篇](12-errors.md)）。需要注意，从网页输入框、命令行参数或环境变量读入的内容默认往往都是字符串，参与算术运算前必须先转换。

常见类型还包括表示真假的布尔值（Python 写作 `True`、`False`，JavaScript 写作 `true`、`false`），以及表示“没有值/空缺”的特殊值（Python 的 `None`，JavaScript 的 `null` 与 `undefined`）。`0`、空文本 `""`、空列表 `[]` 与 `None` 含义完全不同：例如“已读 0 页”是有效进度，而 `None` 可能代表“尚未填写”。在 Python 条件判断中，直接写 `if pages_read:` 会把 `0`、`""`、`[]` 和 `None` 全部当成“假（falsy）”——如果只想检查“是否未填写”，应明确写成 `if pages_read is None:`。

**动态类型**也不意味着值没有类型，而是指类型附着在运行时的对象上、变量名本身不固定绑定某一种类型（同一个变量名先赋整数、后赋字符串在语法上合法，但类型不匹配的操作会在执行到那一行时报错）。与此同时，AI 常在一个项目里同时写 Python 和 JavaScript，这两门动态类型语言在隐式转换上截然不同：在 Python 中，`"12" + 3` 会直接抛出 `TypeError`；而在 JavaScript 中，`"12" + 3` 会把数字转成字符串拼接得到 `"123"`，`"12" - 3` 又会把字符串转成数字相减得到 `9`。**类型注解**（如 `def add(x: int) -> int:`）可以帮助人和静态检查工具（如 `mypy`、`pyright`）理解意图，或供 `pydantic` 等库在特定边界做校验；但**标准 Python 运行时本身完全不会强制检查类型注解**——哪怕给标注为 `int` 的参数传入字符串，Python 也会照常执行，直到遇到不支持的操作才报错。[Python 类型注解文档](https://docs.python.org/3/library/typing.html)明确说明了这一边界。

## 表达式怎样得到结果

能够按规则求出一个值的表达形式，可以称为表达式。`12 * 8` 是表达式，比较 `pages_read > 0` 也是表达式。运算符决定执行哪种操作，括号则可以明确组织顺序。

名字取什么不会自动决定业务含义。把变量命名为 `valid_count`，不等于它已经通过了检查；把字符串命名为 `number`，也不会把它自动变成数字。含义需要由实际代码和输入规则落实。

## 数字表示也有限制

计算机里的小数常使用浮点表示，它能够覆盖很大的数值范围，却不能精确表示所有十进制小数。在通常的 Python 浮点运算中：

```python
print(0.1 + 0.2)
```

会看到 `0.30000000000000004`（JavaScript 中执行 `0.1 + 0.2` 也是同样结果）。这与 IEEE 754 二进制浮点的表示方式有关，不是程序随机算错了一次。因此，代码中通常不应直接用 `a == b` 判断两个浮点数是否相等（可用 `math.isclose` 比较误差范围）；而在涉及金额、汇率等要求精确十进制规则的场景，应改用整数（如以“分”为单位）或十进制专用类型（如 Python 的 `decimal.Decimal`）。[Python 的浮点运算说明](https://docs.python.org/3/tutorial/floatingpoint.html)进一步解释了这一现象。

当 AI 修改一段代码时，可以先看数据从哪里来、是什么类型、经过了哪些转换，以及多个名字是否共享同一对象。这些线索经常比变量名本身更能解释程序行为。
